# Scratchpad Directory (`scratch/`)

## 1. 목적 (Purpose)
이 디렉토리는 일회성 분석 스크립트, 실험적 프로토타입, 임시 조사 도구 등을 위한 개발자 임시 작업 공간(Scratchpad)입니다.

## 2. 운영 정책 (Policy)
- **비프로덕션 격리**: `scratch/` 내의 파일은 프로덕션 코드가 아니며, CI 파이프라인이나 공식 빌드/검증 워크플로에서 직접 참조하지 않습니다.
- **정식 도구 승격**: 프로젝트 전역에서 지속적으로 사용되는 정식 검증, 빌드, 테스트 도구는 `tools/` 디렉토리에 위치해야 합니다.
- **수시 정리**: 작업이 완료되거나 검증이 끝난 임시 스크립트는 필요에 따라 보관 없이 정리할 수 있습니다.
