# Program Specifications (사양서)

Create: Aeronautics 및 CC:Tweaked 비행선 제어 소프트웨어의 프로그램 사양서를 관리하는 디렉토리입니다.
구현할 프로그램의 **요구사항**, **도메인/런타임 제약사항**, **의사코드(Pseudocode)** 등을 포함합니다.

---

## 1. 디렉토리 구조 및 생명주기 (Lifecycle)

사양서는 상태에 따라 다음 4단계 하위 디렉토리로 분류하여 관리합니다:

- `drafts/`: 신규 작성 중이거나 초기 검토 중인 사양서 초안
- `approved/`: 요구사항 및 제약사항 검토가 완료되어 **구현 대기 중**인 사양서
- `implemented/`: 코드베이스 반영 및 검증이 완료된 **구현 완료** 사양서
- `archived/`: 변경, 대체 또는 폐기된 과거 사양서

> **계층 경로 보존 원칙**: 모든 사양서는 상태 디렉토리(`drafts/`, `approved/`, `implemented/`, `archived/`) 간 이동 시 계층 서브디렉토리 구조(예: `1_control/vas/`, `2_guidance/sas/`)를 동일하게 유지해야 합니다.

---

## 2. 상태 전이 규칙 (Lifecycle State Transitions)

```
[ 신규 사양서 작성 ]
        │
        ▼
   ┌─────────┐    검토/승인 완료
   │ drafts/ ├─────────────────────┐
   └─────────┘                     │
                                   ▼
                            ┌──────────────┐     코드 구현 & 검증 완료     ┌──────────────┐
                            │  approved/   ├────────────────────────────►│ implemented/ │
                            │  (구현 대기)  │◄────────────────────────────┤  (구현 완료)  │
                            └──────────────┘      사양서 수정 발생         └──────┬───────┘
                                   │            (drafts 거치지 않고 직행)          │
                                   │                                              │
                                   └──────────────► archived/ ◄───────────────────┘
                                                  (폐기/대체 시)
```

### 사양서 수정 시 규칙 (Revision Protocol)
1. **직행 이동**: 이미 구현 완료(`implemented/`)된 사양서에 수정이 발생하면, `drafts/`를 거치지 않고 즉시 계층 경로를 유지한 채 `approved/`로 이동합니다.
2. **수정 이력 필수 기록**: 수정된 사양서는 상단에 아래 `Revision History` 테이블을 필수로 작성/갱신해야 합니다:

| 버전 | 일자 | 변경 요약 | 변경 사유 |
| :--- | :--- | :--- | :--- |
| v1.1 | YYYY-MM-DD | 센서 타임아웃 파라미터 변경 | 통신 불안정 이슈 대응 |

### 코드베이스 적용 완료 시 규칙 (Completion Protocol)
1. **검증 통과 필수**: 코드베이스에 사양서 내용이 모두 반영되고, 문법 검사·단위 테스트 등 `verification-before-completion` 검증 증거가 확보되어야 합니다.
2. **자동 이동**: 검증이 완료된 사양서는 완료 보고 직전에 에이전트에 의해 `approved/`에서 `implemented/`로 자동 이동합니다.
