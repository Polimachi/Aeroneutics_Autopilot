# ASA :: Aerodynamic Surface Adapter
> **공력 날개 및 조종면 분산 구동기 제어기 (Flight Control Layer)**

- **소속 계층**: `1_control/asa`
- **관할 사양서**: [ASA_PROGRAM_SPECIFICATION.md](../../../docs/specs/1_control/asa/ASA_PROGRAM_SPECIFICATION.md)
- **상위 제어기**: VAS (Vessel Attitude Sustainer)
- **주요 기능**: 고정익/VTOL 기체의 공력 조종면(에일러론, 승강타, 방향타, 플랩) 분산 구동 및 300ms 안전 활공 트림(Safe Glide Trim)
